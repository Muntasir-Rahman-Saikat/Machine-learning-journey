 Earthquake Decision Support Dashboard 
Excited to share my latest data-driven project — the Earthquake Decision Support Dashboard, built to sharpen my technical skills and push my limits in data visualization and geospatial analysis.
This dashboard turns raw USGS earthquake data into real-time insights for geologists and decision-makers, helping identify seismic risk patterns faster and more intuitively.
🔹 What it does
- [x] Upload any USGS .csv → instant clustering, risk scoring & aftershock prediction
 - [x] Executive Summary of recent M6.5+ events
 - [x] Interactive Global Risk Map visualizing hotspots by magnitude and depth
 - [x] Automated recommendations (e.g., “Increase monitoring” when activity spikes)
 - [x] Smart filters by magnitude, depth, tectonic type, and risk level

I built this project to challenge myself — improving my data engineering, visualization, and analytical decision-support skills. Each iteration helped me understand how data can drive real-time action in natural disaster contexts.
